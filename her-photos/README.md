# Drop Her Pictures Here

Place all the photos of her that you want featured in the birthday app inside this folder (`her-photos/`).

- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.heic`
- Optional ordering: Prefix filenames like `01-...`, `02-...` if you want a specific story order.
- Privacy note: This folder's image files are ignored by `.gitignore` by default so raw unencrypted photos are not accidentally pushed to a public GitHub repo.
